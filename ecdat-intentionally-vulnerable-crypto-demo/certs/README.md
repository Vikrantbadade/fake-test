**Security & Safety Notice:**
- This certificate is completely synthetic and disposable.
- It contains NO real identity, sensitive credentials, or real private keys.
- Subject parameters:
  - Common Name (CN): `ecdat-demo.local`
  - Organization (O): `ECDAT Demo`
- Key Type: RSA 2048-bit
- **MUST NEVER BE DEPLOYED TO PRODUCTION ENVIRONMENT.**
